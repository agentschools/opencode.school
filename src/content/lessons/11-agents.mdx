"Agent" is one of the most overloaded words in AI right now. It means something different depending on who's using it. In OpenCode, it has a specific meaning: an agent is a specialized assistant configured for a particular task or workflow — with its own instructions, tools, and permissions.

OpenCode ships with two built-in agents: **Plan** and **Build**.

<AgentPrompt title="Agents" />

## The Plan agent

Plan is for reading files, discussing your project, and thinking through an approach before making changes.

You set `"default_agent": "plan"` in your global config in the [Configuration](/configuration) lesson. That sets your preferred starting agent, but Desktop can still start in Build. Check that Plan is selected before sending a prompt.

Plan's behavior depends on its instructions and configured permissions. Commands or API calls may still have side effects, so it's not a guaranteed protection against unintended changes.

Use Plan when you want to:

- Think through an approach before committing to it
- Explore options and trade-offs
- Ask questions and do research
- Arrive at a clear plan before touching anything

Plan is still the right place to think things through — just don't treat it as an ironclad guarantee that nothing will change.

## The Build agent

Build is the implementation agent. It has full access — it can read files, write files, run shell commands, and make changes. Once you've thought things through in Plan and know what you want to do, switch to Build to carry it out.

## How to switch

In OpenCode Desktop:

1. Look for the agent dropdown below the prompt input. If you only see the model picker, open Settings > General and enable Show agent (scroll down if needed).
2. Return to the prompt and select Plan from the agent dropdown. Enabling Show agent makes the control visible; check the selection rather than assuming it changed.
3. Check the active agent when starting a new session. Switch to Build when you are ready to make changes.

With the dropdown visible, you can also cycle agents with `Ctrl+.` on Windows/Linux or `Cmd+.` on macOS.

In the TUI: press `Shift+Tab` to cycle agents in OpenCode 2.2.6 (`Tab` in older versions). In Desktop, `Tab` moves keyboard focus instead.

## The recommended workflow

Start by checking which agent is active. For quick, straightforward tasks you can switch straight to Build. For anything complex or unfamiliar, select Plan first. It gives you a chance to think out loud with the agent, catch problems early, and arrive at Build with a clear direction.

A useful pattern:

1. Check that Plan is selected, then describe what you want to accomplish.
2. **Explore together.** Ask questions, consider options, refine the approach.
3. **Switch to Build.** Tell it to implement what you planned.

## Custom agents

Beyond Plan and Build, you can define your own agents in `opencode.json` — with custom instructions, specific tools enabled or disabled, a preferred model, and more. Custom agents are useful for recurring workflows like code review, writing, or working with a specific part of your codebase.

For the full reference, see the [agents documentation](https://opencode.ai/docs/agents/).
