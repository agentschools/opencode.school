In this exercise, you'll use AI models to generate images and video — right from OpenCode. You'll work with [Replicate](https://replicate.com), a platform that hosts thousands of open-source AI models and lets you run them through an API.

You'll generate images with [Nano Banana 2](https://replicate.com/google/nano-banana-2) (Google's image generation model built on Gemini Flash), then turn one of those images into a video with [Veo 3.1 Fast](https://replicate.com/google/veo-3.1-fast) (Google's video generation model).

<AgentPrompt title="Run AI models" prompt='Let&#39;s work on the "Run AI models" exercise together!' />

## Prerequisites

You'll need a **Replicate account** and API token:

1. Sign up at [replicate.com](https://replicate.com) (requires a GitHub account)
2. Generate an API token at [replicate.com/account/api-tokens](https://replicate.com/account/api-tokens)
3. Add the token to your shell profile (`~/.zshrc` or `~/.bashrc`):

```
export REPLICATE_API_TOKEN=r8_your_token_here
```

Restart OpenCode Desktop after adding the token so it picks up the new environment variable.

## What you'll do

**Generate images** — Describe what you want and Nano Banana 2 creates it. It handles photorealistic scenes, illustrations, product mockups, and more. It can also edit existing images: pass in a photo along with a text prompt to change backgrounds, swap styles, or combine multiple images.

**Generate video** — Take one of your generated images and bring it to life with Veo 3.1 Fast. Describe the motion or scene you want, and the model produces a short video clip.

OpenCode will use [Replicate's HTTP API documentation](https://replicate.com/docs/reference/http) and each model's API page to check input schemas, create predictions, and retrieve results. No Replicate skill is required.
